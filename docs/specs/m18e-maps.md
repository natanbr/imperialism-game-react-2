# M18e — Seeded random maps and New game options

**Design base `a52d6b4`.** A player can give a friend the settings shown in Stats and both can start on the same coast, with the same neighbours and deposits. The generator uses the existing game pieces. The requirements ledger on this base ends at FR-579 and NR-037. Parked M18d has already used FR-580–587.

## What the sources establish

| Question | Evidence and M18e scope |
|---|---|

**Current entry points.** `engine/world/twoIslands.ts` repeats one 12-column template to make a 24×16 map. `startWorld.ts` founds the two powers, claims each connected island and places the start civilians. `continent.ts` adds four minors, partitions the land into 12 provinces and adds horse ranches. `worlds.ts` assigns the world market to Two islands and the partners market to Continent. `newGame.ts` adds the clock, networks, diplomacy and forces, then `demoStart.ts` applies the human's Demo kit. The kit adds regiments and a frigate only on a world with provinces.

The store's `gameSlice.ts` defaults to Continent, while the engine's `newGame(seed)` defaults to Two islands. Both default to 40 turns and Normal. `ConfirmNewGame.tsx` is the top bar's anchored confirmation with Start new game, Start Demo game and Keep playing. Stats is `HUD/StatsDialog.tsx`. `store/persistence.ts` restores the stored game and checks the save envelope version. `store/sessionReplay.ts` can reconstruct the initial position from the options and replay the logged Orders.

## How to verify the generated worlds

**Inferred generation design.** Use a constructive generator: reserve six country footprints along a common coast, place capital food rings, then grow provinces by adding adjacent land from their seats. Seed the coastline and province boundaries as well as resource placement. Reserve a valid placement for each required site before distributing spare tiles from per-country resource budgets. A prevalidated arrangement with seeded variations bounds the work without retrying arbitrary seeds. Use the national start kit with assigned tiles. The existing `settleIsland` flood-fills a whole landmass and would claim a neighbour's land across a shared border. Preserve minor ownership through `Province.ownerId`. Give minors some developed, discovered inputs to sell through the existing partners market. Their hidden seams, like those of the powers, count only as potential sites until discovered.

Run the FR-588–592 property checks on both sizes for at least seeds 1–64, zero, the largest unsigned seed and a word. For example, `Brete` and `2813929771` must give the same map at the same size. This reproduces the remake's map for that word. The properties apply to **every** output. The sample is regression coverage. Pin a small set of map fingerprints and test negative fixtures for the independent checks.

**Fixed-world comparison.** Capture inputs and outputs at the base and compare exactly after each build task. The pass floors alone would miss a change above a floor.
